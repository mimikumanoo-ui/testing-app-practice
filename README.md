# testing-app-practice

## 概要
COACHTECH 教材 Tutorial 10-5「テスト ハンズオン演習」で作成した成果物です。
ユーザー登録が正しく行われるか、またメールアドレスの重複がブロックされるかを検証する自動テストコードを実装しました。

## 使用技術
- PHP 8.x
- Laravel 10.x
- PHPUnit（テスト）
- Eloquent / Factory

## 学んだこと
- コマンドひとつでプログラムやデータベースの動きが正しいかを自動で検証する仕組み
- テスト用のデータを手動で作るのではなく、ファクトリーを使って自動生成する方法の復習
- テストごとにデータベースをリセットし、毎回同じ状態でテストできるようにすること

## 動作確認
ターミナルで sail artisan test --filter UserTest コマンドを実行し、作成したテストを走らせます。
